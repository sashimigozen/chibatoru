# 新ルール・ローカルテスト

試作版 `0.29.0-test.1`。本番用の `index.html` や公開サイト、Renderの対戦サーバーは変更しない。
このフォルダーのサーバーが、既存ゲームを読み込んで新ルールを適用したページを生成する。
元ファイルの変更位置が一致しない場合は、古いルールを黙って配信せずエラーにする。

## 開き方

同じMacで <http://127.0.0.1:4189/> を開く。

サーバーを止めた後は、このフォルダーの **新ルールテストを起動.command** をダブルクリックする。
ターミナルからは、リポジトリ直下で `node experimental-rules/server.mjs` でも起動できる。
起動用ターミナルを閉じるか Ctrl+C で終了する。

## 遊び方

1. 「テスト設定」で両プレイヤーのデッキと開始時の最大戦意を選ぶ。
2. 「対戦開始」を押す。先攻はプレイヤー1で、初期手札は双方5枚。
3. 出席、攻撃、講義、カード選択は既存の操作を使う。
4. 行動する出席者をクリックして選択する。相手の出席者・本体をクリックすると攻撃、自分の空き席・移動可能な出席者をクリックすると移動・入れ替えになる。同じ出席者を再度クリックすると選択を解除する。
5. ターン終了後は、講義室チェックと演出が完了してから視点が切り替わり、もう一方を手動操作できる。
6. 「テスト設定」のカード名欄から、全カードを操作側の手札に追加できる。未調整カードも除外しない。
7. 攻撃と移動・入れ替えの前には確認を表示する。「テスト設定」の「操作確認」で、それぞれ別々に非表示にできる。設定はこのテストサイトのブラウザに保存する。

本番とは保存先のアドレスが異なるため、デッキは自動共有されない。
標準デッキ・AIバトル用デッキを使用できるほか、デッキJSONを「デッキファイルを読み込む」から追加できる。
この読み込みはページ内のテスト用で、本番のセーブや元のJSONファイルは変更しない。

## 適用したルール

- 攻撃する側・される側とも、通常の範囲は1・2行目と教卓。3行目も効果・能力では対象になり、攻撃された場合は反撃する。
- 通常の本体攻撃は、攻撃可能エリアで次の自分のターンを迎えてから。相手ターン中に前へ移った場合も認める。
- 超陽気は出席ターンの即時本体攻撃が可能。3行目を経由した場合は陽気相当となり、移動で行動権や攻撃回数は回復しない。
- 通常移動は3行目と1・2行目の間のみ。前線内移動、3行目内の横移動、教卓への任意の出入りは禁止。
- 通常移動は本人、入れ替えは双方の行動権を消費する。攻撃済み・講義済みでは通常移動できない。
- 攻撃禁止と移動禁止は別。攻撃禁止でも行動可能なら通常移動できる。
- 能力による移動は行動権を消費・回復せず、出席時効果を再発動させない。
- 任意では禁止位置を選べない。強制・ランダム移動で禁止位置に入った場合は破壊ではなく校外へ送る。満席・広さ不足は移動不成立。
- その場に残ったまま後から出席禁止になった場合は、既存の効果本文に従う。
- 複数マスの出席者は1人として扱う。必要な全マスが空いている場合だけ移動可能。一部でも禁止位置にかかれば校外送り。
- 能力で位置交換する場合はセットで交換した後、席順で判定する。同じ出席者を移動先で再処理しない。
- 前線の注目・超注目は攻撃デコイになる。後列の超注目も範囲内の効果を引き受けるが、対象範囲は広げない。
- 講義は教卓の教師のみ。対象は相手の攻撃可能エリア内で、従来の対象タイプ・装備などの条件を維持する。
- 進化で行動権・本体攻撃資格・攻撃回数の状態をリセットしない。
- 融合6種の終了時効果と病に臥すU太の終了時効果は、処理時に攻撃可能エリアにいる場合のみ。通常移動したターンでも働く。
- 最終形の融合出席者の出席時効果は後列でも発動する。融合出席者は校外へ送られた場合も素材へ分解する。

## 試作版の範囲・制限

- 両側手動操作が検証対象。AIの移動判断やオンライン同期は対象外。
- 外部WebSocket接続はサーバーのCSPで禁止しており、本番の対戦には参加しない。
- 開始時のコイントス・マリガンは試作版の対戦開始では省略する。今回の盤面ルールを早く試すためのテスト用設定。
- 対戦の途中状態は再読み込みで失われる。
- 未調整カードの現行の固有制限は残す。例えば逆張りポータルの「複数行を占有する出席者がいると使用不可」は、調整未決定なので維持。
- 教師を席マスへ出した場合の講義不可や、位置限定カードが強制移動で校外へ送られることは新ルールどおり。
- リーサルクイズ、ダンジョンのクリア可否、既存AIの判断、CP報酬は検証対象外。調整待ちカード一覧は [card-adjustments.md](card-adjustments.md)。

## 検証

`./node_modules/.bin/playwright test --config experimental-rules/playwright.config.cjs`

`node --test experimental-rules/transform.test.mjs`

テストは別のローカルポート4190を起動し、終了時に自動停止する。普段遊ぶ4189は停止しない。

## 更新情報（テスト版のみ）

### システム

- 合意済みの新盤面ルールと、両側手動操作・移動操作を追加。
- 本番とは別オリジンのローカル実験環境を追加。

### 表示・操作改善

- 両側とも3行目との境界に細い間隔を追加。複数マスのカードとクリック範囲も同じグリッドに追従。
- 相手の講義室内の配置を少し下げ、盤面外枠と重ならないように調整。
- 攻撃・移動の出席者選択を共通化し、移動モードのボタンを廃止。攻撃確認と移動・入れ替え確認を個別に設定できるようにした。

### カード調整

- 変更後の全文・能力値と未決定カードは [card-adjustments.md](card-adjustments.md) に記載。
- 正式な公開バージョン・本番の更新情報は変更していない。GitHub Desktop用Summaryは `ver.0.29.0`。
