# チバトル並べ テスト

盤面の表示順は、上から「環境・教師・学生・ヴァンパイア・持ち物」です。内部のタイプ番号やカードIDは変更しません。

通常のカードバトルとは独立した七並べです。通常カードの能力は発動せず、並べ専用の18種類のカードだけが効果を持ちます。
既存の教室背景、カード裏面、水色の対戦準備の雰囲気を使用します。
対戦画面は相手の手札を左、場を中央、自分の手札を下に配置し、通常版のMENU・ログ位置を維持します。
最初の配札は、通常版のカード部品を手札と同じ大きさのまま滑らかに移動します（回転・拡縮・確認用の寄り道なし）。全員へ同時に1枚ずつ、480msの移動と120msの間隔で配ります。つかんだカードの表示は `ChibattleHandDrag` を通常版と共有します。
カード表面は通常版と同じ `card-face.js` で描画し、通常版 `index.html` の実際のスタイルを分離した表示領域へ読み込みます。並べ専用の色・枠・文字配置へ描き直しません。カードの縮小基準も通常版と同じ420×640です。
このスタイル読み込みのため、HTMLファイルを直接開かず、下記のHTTPテストサーバーから開いてください。通常版のゲームスクリプトやセーブ処理は読み込みません。
通常の七並べには毎ターンのドローはなく、配札時だけドロー演出を使用します。

## ローカルで試す

リポジトリのルートで `node tools/serve-narabe-test.cjs` を実行し、
`http://127.0.0.1:8790/narabe-test/` を開きます。
CPU戦は接続不要。複数のブラウザ／独立したタブで同じ部屋番号に入ってテストできます。
このローカルサーバーは自分のPCからだけアクセスできます。

## 友だちとオンラインで試す

フロントをGitHub Pagesへ、`server` 以下を既存Renderサービスへ反映する必要があります。
通常版に新しいルールを混ぜず、WebSocketの `/narabe` パスだけを別の部屋管理へ振り分けます。
部屋・ゲーム状態・操作メッセージは通常対戦と共有せず、通常対戦のクラウドログへも送信しません。
フロントの「接続先の設定」で別サーバーを指定することもできます。
まだ公開していないローカル変更を、公開済みと扱わないでください。

## 仮ルール・制限

- 2〜6人、通常43枚。採用表は `server/narabe-cards.js`。学生・教師・ヴァンパイア・持ち物・環境を各1列とし、戦意1〜10で並べます。
- 教師6：かき揚げ教師、ヴァンパイア6：ジョブズウッディ、ヴァンパイア9：窓辺イーター、持ち物8：一旦を追加。環境7に全ロック、環境8にコートダジュールを採用。環境10は空席とし、通常のカオスワールドは配りません。
- 各タイプの戦意5の5枚は場へ移し、残り38枚を手札とします。配札で「狼(いっぴきおおかみ)」を持っていた人から順に1枚出すかパス。戦意5の移動後は手札枚数が人によって異なる場合があります。
- カードがない7マスは、除去できない・能力のない「空席」を最初から置きます。空席は手札へ配りません。途中の実カードは飛ばせません。
- カード名・戦意・タイプ・攻撃力・体力は通常版と同じ。能力を発動せず、攻撃力・体力も勝敗や配置の判定に使いません。戦意は固定値で、環境による変動もありません。
- パスは合計3回、4回目で脱落。脱落者のカードは表向きで場の対応位置に配置。
- 脱落者のカードが飛び地に出ても、戦意5から間がつながるまでは飛ばして出せません。
- 専用カードは全18種類から全プレイヤーを通して重複なしで1人3枚。通常カードとは別に、同じ手札エリアの右側に白銀枠で表示します。えースペのオレンジを使いません。
- 専用手札は名前だけの縦長の短冊。効果本文は使用確認とルール一覧で確認します。パスと自分の情報は盤面内の右下に置き、通常手札は画面幅・枚数に応じた重なりと段数で横スクロールせず表示します。
- 専用カード使用時は通常版の `revealToTrash` の動きと1.45秒の表示時間を再利用します。使用成功の公開イベントを全接続へ送り、CPU・相手の使用時も同じ演出を表示してから次の状態へ進みます。
- 選択中は「盤面を見る」で選択画面を一時的に隠し、盤面・ログを確認できます。「選択画面に戻る」で選択を保持して復帰します。一時非表示は選択のキャンセル・確定ではなく、情報収集も確認終了するまで有効です。
- 自分の手番の通常配置前に専用カードを1枚まで使用可能。消費したら補充しません。通常手札が0枚であがり、専用手札の残枚数は勝利条件に含みません。
- あがり順に上位、脱落順に下位。最後の1人は残った順位で終了。
- 全員が準備OKならホストが開始。指定人数までCPUが入ります。
- 43枚を配った状態から、各プレイヤーの手札にある戦意5を1枚ずつ場へ移す演出を行い、「7枚 → 6枚」のように枚数の変化を表示します。配札・戦意5の移動中は操作不可。全員の開始演出終了を確認してから手番を開始します（無応答時は30秒で解除）。
- カードはクリック、または対応する場へのドラッグで出せます。出せないカードも持ち上げられますが、不正なドロップでは場へ出ません。
- 他人の通常・専用手札はサーバーから送信しません。公開授業の公開1枚、および情報収集・千里眼で許可された使用者の確認画面だけが例外です。確認画面を閉じると再送しません。操作・選択の権限と内容はサーバーで検証します。
- 開始前の退出は席を解放し、先頭の人へホストを移します。準備OKは全員解除します。
- 対戦中の切断・退出は脱落。再接続・観戦・再戦の同室継続は未対応。
- 部屋状態はメモリ上のみ。サーバー再起動や2時間の無操作で部屋は消えます。

## 専用カードと処理

効果文の唯一の定義は `server/narabe-specials.js`。開始画面のルール一覧、専用手札、使用確認画面はここから表示します。通常版のカード名・戦意や能力を上書きしません。

1. カオスワールド：使用した自身を除いて通常・専用を別々に再配布。各人の通常枚数と、使用済みカードを取り除いた専用枚数を維持。
2. 追加手番：通常配置を追加1回。専用の使用回数は増えない。追加せず終了することも可能。
3. 全員交換：全員が通常1枚を選ぶまで停止し、現在の進行方向で次の人へ同時に渡す。選択結果は確定まで非公開。
4. 配置禁止：自分の次の手番開始までタイプ1つを禁止。狡猾老獪などによる配置も禁止。使用者が脱落した場合は解除。
5. パス回復：使用済みパスを1減少。0なら使用不可。
6. 情報収集：相手1人の通常手札すべてを使用者だけに表示。確認終了の応答まで進行停止。
7. 千里眼：相手全員から通常手札をランダム2枚まで使用者だけに表示。
8. 狡猾老獪：選んだ通常1枚を接続を無視して配置し、通常配置を残す。禁止は無視しない。
9. 混乱：対象の次の手番開始時に合法な1枚をランダム配置して、その手番を終了。合法なカードがなければ混乱だけを解除し通常手番。
10. リバース：進行方向を反転。
11. 交換留学：自分が選んだ通常1枚と対象のランダム通常1枚を交換。
12. 強制登校：対象本人が合法な通常1枚を選んで直ちに配置。通常手番を消費せず、出せなければ省略・パスも加算なし。
13. 連鎖出席：通常配置後に同タイプ・戦意±1の合法な通常1枚を任意で追加。1回だけ。
14. 公開授業：全員が通常1枚を選んだ後に公開。本人の次の手番開始、配置・交換・カオスで手札を離れた時に解除。
15. 手番指名：次の人を指名。その後はその人を起点に現在の進行方向で継続。
16. 特別補講：合法な通常カードがないときだけ使用可能。その手番のパス加算を免除。
17. 一斉点呼：現在の手番の人から進行方向に1人ずつ、その時点で合法な通常1枚を配置。出せない人は省略、通常手番・パス回数は消費しない。
18. 自主休講：合法カードがあってもパスを増やさず手番を終了。

あがり・脱落済みのプレイヤーは専用カードの全員処理・対象指名から除外します。手番外でも選択対象本人は応答可能です。切断した人の選択待ちを除去し、残りの人で続行します。

## テスト

- `node --test server/narabe.test.js server/narabe-specials.test.js`：18種類、非公開情報、切断、2〜6人・500戦、実WebSocketの6接続。
- `npx playwright test --config=narabe-test/playwright.config.cjs tests/narabe.spec.js`：PC・スマホ・複数画面・配札・ドラッグ・別手札。
