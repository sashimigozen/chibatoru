# 無料のオンラインログ保存を有効にする

コードを更新しただけではクラウド保存は有効になりません。Cloudflareの無料アカウントにD1データベースを作り、Renderへ次の3つを設定します。有料プラン、ドメイン購入、Workersの新規デプロイは不要です。

## 1. Cloudflare

1. https://dash.cloudflare.com/ にログインし、「D1」を開く。
2. データベースを作成し、名前を `chibatoru-online-logs` にする。無料プランのまま進める。
3. データベース詳細から「Database ID」と「Account ID」を控える。
4. プロフィールの「API Tokens」でカスタムトークンを作る。対象のアカウントだけにD1の読み書き権限（D1 Edit / D1 Write）を与える。Global API Keyは使わない。
5. トークンはチャット、画像、GitHubへ貼らない。次のRenderの秘密の環境変数へ直接入力する。

テーブルはサーバーが自動作成するため、SQLの貼り付けは不要です。APIは公式のD1 REST APIを使用します。

## 2. Render

`chibatoru-online` → Environment に次を追加する。

| 環境変数名 | 値 |
| --- | --- |
| `CHIBATORU_D1_ACCOUNT_ID` | Account ID（32文字） |
| `CHIBATORU_D1_DATABASE_ID` | Database ID（UUID） |
| `CHIBATORU_D1_API_TOKEN` | 作成した秘密のAPIトークン |

ログ管理用の `CHIBATORU_LOG_ADMIN_PASSWORD` も引き続き必要です。既存のものを維持してください。フロント・サーバー双方の更新を公開し、Renderを再デプロイします。

## 3. 確認

1. `/admin/logs` を開き、管理者パスワードでログインする。
2. 「クラウド保存: 設定済み」を確認する。この表示だけでは接続成功の確認にはなりません。
3. 人間同士でオンライン戦を行い、終了から数秒後に「クラウド保存済みログ」を開く。
4. 試合が掲載され、JSONを保存できることを確認する。待機や通信失敗なら30秒ごとに再試行する。

記録は試合ごとのJSONをgzip圧縮し、必要なら複数行に分割して保存します。更新中に通信が切れても、保存済みの前の版を読める方式です。試合中は約30秒間隔、終了時は約1.2秒後から保存処理を行います。送信待ちのままRenderが停止すると、最後の未送信分は失われる可能性があります。重要な試合は終了画面右上の「ログを保存」も併用してください。

ホストの保存ボタンはサーバーにある詳細JSONを取得します。サーバーへ接続できない場合は、ホスト端末の詳細記録を保存します。ゲストは自分視点の公開ログのみです。端末由来のログは自動で「検証済みの分析候補」とはせず、不具合調査用として区別します。

Renderの一時領域が消えても、D1に保存済みの試合は「クラウド保存済みログ」から一覧・個別取得できます。通常一覧の保持件数とは別で、D1の試合を勝手に削除しません。CPU戦はクラウド保存・AI改善用分析の対象外です。

## 無料枠について

2026年10月21日確認時点で、D1 Freeは1データベース500MB、アカウント合計5GB、1日10万行書き込みまでです。最初のこの実装は1データベースを使用するため、利用できる容量は500MBです。上限に達した場合は管理画面へ未保存表示を出し、自動で有料へ移行したり、古い試合を削除したりはしません。無料で無制限・永久保証の保存ではありません。容量が増えたら端末へバックアップして整理する方針を決めてください。
